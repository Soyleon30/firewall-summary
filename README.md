# 防火墙申请汇总工具

一个 Windows 桌面小工具，用于递归统计指定目录下的防火墙申请表，并导出 Excel 汇总。

## 运行环境

- Windows
- Python 3.10 或更高版本

安装依赖并启动：

```bat
python -m pip install -r requirements.txt
python main.py
```

打包成单文件 exe：

```bat
build_windows.bat
```

打包完成后运行：

```bat
dist\FirewallSummary.exe
```

## 扫描规则

- 默认目录框预填 `D:\【维护部】`，也可以在界面里重新选择目录。
- 递归查找 `.xlsx`、`.xlsm`、`.xls` 文件，跳过 Excel 临时文件 `~$...`。
- 只处理位于名称包含 `火墙` 的目录下的 Excel 文件。
- 对每个 Excel 文件读取所有 Sheet。
- 固定读取 C 列为原地址、F 列为目的地址、H 列为目的端口。
- 申请日期优先从最近的申请目录名提取；如果该目录名没有日期，会继续向父目录查找日期前缀。
- 支持 `2024-08-05`、`2024.08.05`、`2024_08_05`、`2024年8月5日`、`20240805` 等日期前缀。
- 同一申请目录内，原地址 + 目的地址 + 目的端口完全相同的记录只保留首条。
- 不同申请目录中出现相同原地址 + 目的地址 + 目的端口时，全部保留，并标注为跨目录重复。

## 导出内容

导出的 Excel 包含三个 Sheet：

- `汇总明细`：日期、申请目录、文件名、Sheet、来源行、原地址、目的地址、目的端口、重复组、组内数、重复状态。
- `重复组`：只汇总跨目录重复的申请组合。
- `统计`：扫描文件数、保留记录数、同目录去重数、异常文件等。

在界面结果表中双击某条记录，可以在 Windows 资源管理器中定位到来源文件。
