防火墙申请汇总工具
==================

运行要求
--------
1. Windows 10 或 Windows 11，64 位。
2. 目标电脑不需要安装 Python、Excel 或其他第三方组件。
3. 解压发布包后，双击 FirewallSummary.exe 即可运行。

使用方法
--------
1. 选择要扫描的目录，默认值为 D:\【维护部】。
2. 点击“开始扫描”。
3. 扫描完成后查看明细和重复标记。
4. 点击“导出Excel”保存汇总文件。

说明
----
1. 软件已包含 Python 运行时、Tk 图形组件、openpyxl 和 xlrd。
2. 第一次启动单文件 exe 时，Windows 可能需要几秒钟解压内部运行文件。
3. 如果 Windows SmartScreen 提示未知发布者，这是因为 exe 未做商业代码签名。
4. 本工具不会联网，不会上传扫描目录或 Excel 内容。
